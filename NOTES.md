# Strata: заметки по проекту

Документ для продолжения работы без исходной переписки: что это, как запустить, что сделано, почему так, что осталось.

## Что это

Серия дизайн-концептов в жанре «дизайн-инженерия» (живые прототипы для постов в соцсетях). Тема одна: **налоговый сейф фрилансера/студии, нарисованный как изометрический график**. Каждая плита в изометрической башне — один налог:

- **высота плиты** — сколько нужно отложить (масштаб 1 юнит = $164 в концептах 01–02);
- **сплошная заливка** — сколько уже лежит в сейфе;
- **контур без заливки** — сколько осталось;
- **штриховка / точки / красный срез** — прогноз или сумма, которую сейчас переводят.

Сделано три визуальных направления на одних и тех же данных и одном и том же изометрическом движке.

| Файл | Направление | Референсы |
|---|---|---|
| `concepts/01-strata-modes.html` | Светлая финтех-карточка, 3 режима отрисовки: Paper / Blueprint / Night | Карточка Keel, разнесённая дискета (blueprint), линейная изометрия, стеклянные 3D-иконки, тёмные фитнес-виджеты |
| `concepts/02-strata-fui.html` | FUI-терминал: тёмная сетка HUD-панелей | FUI Kit (бирюзовый/мятный, полосатые бары, таблицы, циферблаты) |
| `concepts/03-strata-soft.html` | Мягкий тактильный тёмный стиль, модалка «пополнить сейф» | Тёмный checkout-модал с красно-оранжевым акцентом |

Референсы в репозиторий **не добавлены**: это чужие изображения (Dribbble и т. п.), а репозиторий может быть публичным. Их описание есть в таблице выше и ниже в разделах про каждый концепт. Если нужно, положите их в папку `refs/` вручную.

## Как запустить

Сборки нет. Каждый концепт — один самодостаточный HTML-файл (CSS и JS внутри, внешние только шрифты Google Fonts).

- Просто открыть `index.html` (страница-лаунчер) или любой файл из `concepts/` в браузере.
- Или локальный сервер: `python3 -m http.server 8000` → http://localhost:8000
- GitHub Pages: Settings → Pages → Branch `main`, папка `/ (root)`; `index.html` станет главной.

Скриншоты-проверка (необязательно):

```bash
npm install
npx playwright install chromium
npm run shots
```

Скрипт `scripts/screenshot.js` открывает каждый концепт на десктопе (1360px) и телефоне (390px), сохраняет PNG в `screenshots/` и печатает горизонтальное переполнение и JS-ошибки (код выхода 1, если что-то не так).

### Публикация обратно в Claude Artifact

Файлы в `concepts/` обёрнуты в стандартный `<!doctype><head><body>` — такой же каркас добавляет просмотрщик артефактов, поэтому локально страница выглядит так же, как в артефакте. Сам артефакт ожидает **только содержимое** без обёртки:

```bash
python3 scripts/to-artifact.py concepts/03-strata-soft.html > strata-soft.artifact.html
```

Скрипт вырезает всё между `<!-- ARTIFACT:START -->` и `<!-- ARTIFACT:END -->`. Проверено: результат побайтно совпадает с исходниками опубликованных артефактов.

## Данные (вымышленные, одинаковые во всех концептах)

- Квартал Q4 2026, «сегодня» = пятница **30 октября 2026**, срок = **15 января 2027**. Таймлайн: 20 недель от понедельника 31 августа 2026. В коде время `t` измеряется в неделях: `T0 = 60/7` (сегодня), `TD = 137/7` (срок).
- Слои (снизу вверх): Federal income (Form 1040-ES) 5,950 / 12,400 · Self-employment (Schedule SE) 2,600 / 5,200 · State estimate (CA 540-ES) 3,170 / 4,800 · Sales tax (3 штата, до 31 янв) 1,060 / 2,200. Итого **12,780 / 24,600**.
- Правило автосбережения: 30% каждого клиентского платежа, ежедневный перевод в «Tax vault ••4418». Прогноз после «сегодня»: остаток 11,820 линейно за 11 недель (~1,075 в неделю).
- Недельные переводы: в 01 — `[1120, 1640, 920, 2180, 760, 1480, 1910, 1330, 1440]`, в 02 — `[1110, 1650, 930, 2190, 750, 1470, 1920, 1320, 1440]`. Во втором кратны 30, чтобы суммы платежей в журнале были круглыми (перевод = 30% платежа). Сумма та же — 12,780.
- Клиенты в журнале (02) вымышленные: Nordvik Labs, Rowan & Hale, Pale Fire Media, Studio Kestrel, Blue Axis, Okapi Films. Бренд из референса (Keel) намеренно не использовался.

## Как устроен изометрический движок (общий для всех трёх)

- Геометрия считается в JS, вывод в **SVG-полигоны**. Проекция: `P(x,y,z) = [CX + (x−y)·cos30·S, CY + (x+y−центр)·0.5·S − z·S]`. Видны три грани коробки: верх, правая (x=x1), левая (y=y1).
- Каждый слой рисуется в порядке: грани «призрака» (контур цели) → задние рёбра → сплошная часть (сохранено) → прогноз → **передние рёбра призрака поверх** (иначе сплошная часть закрывает рёбра, которые физически ближе к зрителю). Слои — снизу вверх (алгоритм художника).
- Разнесённый вид: у каждого слоя добавляется зазор `GAP·e`, где `e` от 0 до 1 анимируется пружиной.
- Анимации на простых пружинах (полунеявный Эйлер, демпфирование ~0.75, лёгкий перелёт). rAF-цикл крутится только пока что-то движется.
- «Ящик»: наведённая/выбранная плита выезжает по оси +x на 10–14 юнитов. Чтобы наведение не мигало, поверх лежат **невидимые хит-полигоны** с запасом на выезд.
- Цвета граней задаются CSS-токенами (`color-mix`, `fill: url(#pattern)`), поэтому один и тот же SVG перекрашивается сменой токенов без изменения разметки.

## Что сделано

### 01 · Isometric modes (`01-strata-modes.html`)
- Карточка «Q4 tax set-aside»: крупная сумма, сегментированный бар, статус темпа (ahead / on pace / behind), список налогов, гистограмма недельных переводов как скраббер.
- Три режима: **Paper** (тёплый градиент с зерном), **Blueprint** (синие линии на точечной сетке, моно-шрифт IBM Plex Mono, весь интерфейс как чертёж, подписи FIG_02), **Night** (тёмно-синий, стеклянные плиты с бликом и свечением). Переключение — шторка через View Transitions API (в Chrome, в остальных браузерах мгновенно).
- По умолчанию режим зависит от темы зрителя: светлая → Paper, тёмная → Night.
- Выноски со стрелками в разнесённом виде, размерная линия «$24,600» в собранном, падающие монеты при проигрывании, прогноз штриховкой.
- Клавиши: `E` разнести/собрать, `1 2 3` режимы, `Space` проиграть квартал, `← →` по неделям на скраббере.

### 02 · FUI terminal (`02-strata-fui.html`)
- Лист из панелей: VAULT.Q4 (изометрия), SP_VAULT.Q4 (крупные значения, таблица TARGET/TO GO/WEEKS/PACE, два полосатых бара «заполнение vs прошедшее время»), CODE.E (налоги плитками FD/SE/CA/SX с ползунками), CODE.C (полосатая гистограмма-скраббер с ромбами), COMMS.B (журнал платежей, привязан ко времени), CODE.C system (вордмарк STRATA + 3 циферблата), README.
- Плиты залиты диагональными полосами (как бары в FUI Kit), прогноз — точками, контур — пунктиром.
- Скан-плоскость по башне (`S` и один раз при загрузке), «расшифровка» заголовков при загрузке, живые часы, падающие кубики-пакеты и новые строки журнала при проигрывании.
- Шрифты: Rajdhani + Share Tech Mono. Только тёмная тема — осознанно.
- Клавиши: `E`, `S`, `T` (вернуться к сегодня), `Space`, `← →`.

### 03 · Soft checkout (`03-strata-soft.html`)
- Модалка «Tax vault» по структуре checkout-референса: позиции = налоги (выбранный с красной иконкой), поле суммы + `Fill` вместо купона, Subtotal/Tax/Discount → In vault / Top-up (плашка `+8%`) / Left to set aside, Total → Vault after, Cancel / `Move $1,000`.
- Плиты — серый «пластик» с градиентами и бликом по передним рёбрам; выбранный слой плавно перекрашивается в красный; сумма к переводу — пульсирующий полупрозрачный красный срез.
- `Move`: спиннер → монета по дуге → срез становится сплошным → «Moved ✓». `‹` отменяет последний перевод (`Z`), `✕` сбрасывает демо, `Stack/Split` (`E`).
- Шрифт: системный (SF Pro на Apple), запасной — Geist. Только тёмная тема — осознанно.

## Принятые решения и почему

- **Один HTML-файл на концепт, без фреймворков и сборки.** Требование формата Claude Artifacts (всё инлайн, внешние скрипты только с CDN), быстрые итерации, сразу работает на GitHub Pages и как вложение.
- **SVG, а не Canvas/WebGL.** Чёткие тонкие линии, события наведения на каждой плите, стилизация через CSS-токены (на этом построена смена режимов). Для 4 слоёв перерисовка каждый кадр дешёвая.
- **Одна геометрия — несколько отрисовок.** Главная «фишка» для поста: та же модель данных, разный визуальный язык. Поэтому движок копируется между файлами, а не переписывается.
- **Кодирование данных формой, а не только цветом:** высота = цель, заливка = сохранено, контур = остаток, текстура = прогноз. Работает и в монохромном Blueprint.
- **В 03 акцент только один (красный)** — как в референсе: им отмечены выбор и действие, всё остальное в серых тонах.
- **Состояние не сохраняется** между перезагрузками: это демо, оно должно каждый раз открываться в одинаковом виде.
- **Каркас с маркерами ARTIFACT:START/END** вместо отдельных копий: один источник правды и для браузера, и для артефакта.
- **Интро-анимации стартуют из видимого состояния** (страница полная уже на первом кадре — важно для превью и скриншотов).
- Уважается `prefers-reduced-motion`: пружины мгновенные, монет/скана нет.

## Что не доделано / идеи

- Нет записи видео/GIF для постов — можно добавить в `scripts/` сценарий Playwright с `recordVideo` (раскрыть → сменить режим → проиграть).
- Цвета режимов не вынесены в токены (DTCG / Tailwind v4) — сейчас это CSS-переменные внутри каждого файла.
- Движок продублирован в трёх файлах; если концептов станет больше, стоит вынести его в общий модуль (тогда понадобится сборка для артефактов).
- Доступность частичная: строки списка и скраббер управляются с клавиатуры, но сами SVG-плиты не фокусируются, изменения цифр не озвучиваются (`aria-live` нет).
- В 01 и 02 «ящик» по наведению на телефоне срабатывает только по тапу/фокусу на строке.
- Данные зашиты в код, реального API нет.
- Шрифты грузятся с Google Fonts: офлайн будут системные запасные.
- Нет экспорта в Figma (Figma-коннектор был доступен, но не использовался).
